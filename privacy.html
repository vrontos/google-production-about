Privacy policy

Last updated: 24 November 2026

This tool has exactly one user, its owner. It reads only the owner's own data, only with the owner's consent, and only read-only. It keeps that data in the owner's own Google account.

No data is shared with, sold to, or shown to anyone else, and none is used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be withdrawn at any time at myaccount.google.com/permissions.
